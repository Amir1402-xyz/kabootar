# کبوتر 🕊️

**پراکسی محلی تلگرام برای اندروید**

تلگرام بدون وی‌پی‌ان، از مسیر کلادفلر. فقط تلگرام، بقیه‌ی برنامه‌ها دست نمی‌خورن.

[دانلود آخرین نسخه](https://github.com/Amir1402-xyz/kabootar/releases/latest) · [کانال تلگرام](https://t.me/parsv2r)

</div>

## چطوری کار می‌کنه

یه پراکسی MTProto روی خود گوشیت روشن میشه (`127.0.0.1`). تلگرام به همین وصل میشه و کبوتر ترافیک رو با WebSocket از پشت کلادفلر به سرورهای تلگرام می‌رسونه. سروری وسط نیست که بشه آی‌پیش رو بست.

```
تلگرام ← پراکسی روی گوشی ← WSS از مسیر کلادفلر ← سرورهای تلگرام
```

## نصب و استفاده

1. از [صفحه‌ی دانلود](https://github.com/Amir1402-xyz/kabootar/releases/latest) فایل `universal` رو بگیر و نصب کن.
2. کبوتر رو باز کن و روی لوگوی تلگرام بزن تا روشن بشه.
3. دکمه‌ی «اتصال در تلگرام» رو بزن، تلگرام باز میشه، Connect رو بزن. تمومه.
4. توی تنظیمات گوشی، بهینه‌سازی باتری رو برای کبوتر خاموش کن که سیستم تو پس‌زمینه نبندتش.

اگه دکمه تلگرام رو باز نکرد، لینک پایین صفحه رو کپی کن، تو Saved Messages بفرست و روش بزن.

## چند تا نکته

- وی‌پی‌ان باید خاموش باشه، وگرنه معلوم نیست ترافیک از کجا رفته.
- کلادفلر رو روشن نگه دار. مسیر مستقیم تو ایران معمولا بسته‌ست.
- اگه یه روز دامنه‌ها بسته شدن، لیست جدید خودکار از گیتهاب پروژه‌ی اصلی میاد. توی تنظیمات هم میشه دامنه‌ی خودت رو بدی.
- فقط تلگرام رو رد می‌کنه. برای بقیه‌ی برنامه‌ها کاری نمی‌کنه.

## اعتبار

کبوتر نسخه‌ی فارسی و ساده‌شده‌ی این دو پروژه‌ست و بدون اون‌ها وجود نداشت:

- [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy): ایده و پروژه‌ی اصلی، و دامنه‌های کلادفلری که کبوتر ازشون استفاده می‌کنه (MIT)
- [amurcanov/tg-ws-proxy-android](https://github.com/amurcanov/tg-ws-proxy-android): نسخه‌ی اندروید که کبوتر مستقیم روش ساخته شده (GPLv3)
